# dfe_resumo_pedido

# Resumo do Pedido

Projeto desenvolvido para a disciplina de Design Front End, curso de Análise e Desenvolvimento de Sistemas, utilizando HTML e CSS, com o objetivo de reproduzir um card de resumo de pedido baseado em um design de referência.

O projeto possui layout responsivo, informações do plano, botões interativos e estilização utilizando as cores e fonte indicadas no projeto.

## Como executar

1. Clone o repositório:
`git clone https://github.com/jhenriquearaujo/dfe_resumo_pedido.git`

2. Entre na pasta:
`cd dfe_resumo_pedido`

3. Clique com o botão sobre o arquivo `index.html`, clique em "Copiar o caminho" e cole no navegador ou utilize o Live Server no Visual Studio Code.

## Tecnologias

HTML e CSS.
